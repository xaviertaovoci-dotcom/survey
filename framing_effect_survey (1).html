One-time setup · about 3 minutes

Connect JSONBin

A free mini-database that needs only a personal email.

1
Create a free JSONBin account
Go to jsonbin.io → click Sign Up. Use any personal email — takes about 30 seconds. No credit card.
2
Get your Master Key
After logging in, click your profile icon (top right) → API Keys. Copy the Master Key — it starts with $2a$10$...
3
Create a new bin
Click the + button (or Create Bin) in your JSONBin dashboard. In the editor, type [] as the content (just two square brackets — an empty list). Give it the name survey-responses. Click Create. The Bin ID will appear in the URL bar — it looks like 6651a3f... — copy it.
4
Paste both values into this file
Open framing_effect_survey.html in any text editor. Find these two lines near the top of the script and replace the placeholders: const BIN_ID = 'YOUR_BIN_ID'; const MASTER_KEY = 'YOUR_MASTER_KEY'; Save the file and open it in your browser — this setup screen disappears.
5
Deploy on Netlify Drop
Go to app.netlify.com/drop, drag your edited file onto the page. You get a free public URL in about 10 seconds — share that with your class!

After step 4, re-open the file locally to confirm the setup screen is gone before uploading to Netlify.
